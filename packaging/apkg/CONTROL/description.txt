Cron Manager is a lightweight native ASUSTOR ADM GUI for the real root crontab. It preserves existing system entries, validates schedules, creates a full backup before every change, supports Run Now and execution history for managed jobs, portable managed-job export/import, full crontab archival export, one-click backup restore, and verified in-app updates from the official GitHub repository. One static ARM64 binary; no Docker, database, Node.js, PHP, cloud account, or telemetry.
