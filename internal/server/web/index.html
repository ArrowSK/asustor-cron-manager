Design principles

  • ✓System crontab remains the source of truth.
  • ✓Unknown lines are left byte-for-byte untouched when unrelated jobs are edited.
  • ✓Managed jobs are converted back to plain cron entries on uninstall.
  • ✓No Docker, database, Node.js or cloud dependency.
